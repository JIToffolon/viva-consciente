# UI \& Design System - Ecosistema Viva Consciente## 1\. Filosofía de Diseño* **Mobile-First Radical:** La aplicación está diseñada principalmente para ser consumida desde smartphones tras escanear un código QR en eventos. El diseño de escritorio es una adaptación responsive limpia y centrada (máximo ancho de contenedor legible).* **Lectura Rápida (5 minutos):** Jerarquía visual clara. Contenido escaneable mediante títulos concisos, bajadas de 2 a 3 líneas y niveles desplegables para profundizar.* **Estética:** "Ciencia + Naturaleza" (premium, sobrio, botánico-clínico, alta legibilidad).\---## 2\. Tipografía \& Escala de Textos* **Fuente Principal:** Inter, Geist Sans o Roboto (Sans-serif limpia, moderna y altamente legible en pantallas pequeñas).* **Jerarquía:**  * **H1 (Pantalla / Hero):** `text-2xl md:text-3xl font-bold text-brand-text-main leading-tight`  * **H2 (Sección / Producto):** `text-xl md:text-2xl font-semibold text-brand-text-main`  * **H3 (Bloque / Desplegable):** `text-base md:text-lg font-medium text-brand-teal`  * **Bajadas (Hero Subtitle):** `text-sm md:text-base text-brand-text-muted leading-relaxed`  * **Cuerpo / Ficha Técnica:** `text-sm text-brand-text-main leading-normal`  * **Badges / Tags:** `text-xs font-semibold uppercase tracking-wider`\---## 4\. Componentes UI Clave### 4.1. Barra de Navegación Inferior Fija (Mobile Bottom Bar)* **Comportamiento:** Fija en la parte inferior (`fixed bottom-0 left-0 right-0 z-50`).* **Altura:** `h-16` con backdrop blur (`bg-brand-surface/90 backdrop-blur-md border-t border-slate-200`).* **Items de Navegación (4 botones obligatorios):**  1. **Inicio:** Ícono `Home` (Lucide) -> `/app` (Portada).  2. **Productos:** Ícono `Leaf` / `Grid` -> `/app/superalimento` o vista catálogo.  3. **Área PRO:** Ícono `UserCheck` / `FileText` -> `/pro` (Vademécum profesional).  4. **Contacto:** Ícono `MessageCircle` / `Phone` -> `/app/contacto`.* **Estado Activo:** Color `brand-teal` con indicador sutil superior o de fondo.### 4.2. Botón de Acción Flotante (WhatsApp CTA)* **Posición:** Flotante sobre el menú inferior (`fixed bottom-20 right-4 z-40`).* **Estilo:** Botón circular verde esmeralda con sombra pronunciada (`shadow-lg bg-\\\\\\\[#25D366] text-white p-3.5 rounded-full hover:scale-105 transition-transform`).* **Enlace:** `https://wa.me/<NUMERO>?text=<MENSAJE\\\\\\\_CODIFICADO>` con mensaje predeterminado profesional.### 4.3. Hero Section Estándar por Pantalla* Estructura consistente en las 15 vistas:  * Imagen de cabecera optimizada (aspect ratio móvil 16:9 o 4:3 con overlay suave).  * Badge de contexto (ej. "Área Profesional" o "Unidad Funcional").  * Título Principal (H1).  * Bajada concisa (máximo 2 a 3 líneas).  * Botón CTA principal de ancho completo en mobile (`w-full sm:w-auto`).### 4.4. Ficha Técnica Modular V2 (Productos Ancla)Estructura editorial estricta con acordeones desplegables (`Accordion` Headless):1. **Cabecera Ficha:** Nombre comercial, badge de categoría, presentación (ej. 100g / 30 dosis).2. **Descripción Funcional Breve:** 2 líneas sin promesas de cura ni claims no validados.3. **Acordeón 1 - Composición Validada:** Lista de ingredientes, partes utilizadas y estandarizaciones validadas.4. **Acordeón 2 - Uso Informativo:** Forma de consumo orientativa según rótulo vigente.5. **Acordeón 3 - Precauciones y Seguridad (Alerta visual):** Caja con borde suave de advertencia (`bg-amber-50 border-l-4 border-amber-500 text-amber-900`) indicando embarazo, lactancia, medicación y derivación al médico tratante.6. **Footer de Ficha:** Fecha de actualización visible + Botón directo a WhatsApp/Contacto PRO ("Consultar Ficha Técnica").### 4.5. Tarjeta Resumen (Catálogo General)* Tarjeta compacta (`bg-white rounded-xl p-4 shadow-sm border border-slate-100 flex flex-col justify-between`).* Incluye: Nombre, badge de estado ("Borrador" / "En Validación" / "Publicado"), presentación y botón para solicitar datos al área profesional.\---## 5\. Reglas de Responsive \& Espaciado* **Layout Container:** `max-w-md mx-auto min-h-screen pb-24` (en mobile aprovecha el 100% de la pantalla; en pantallas grandes se centra como emulador de aplicación).* **Padding Horizontal Estándar:** `px-4 sm:px-6`.* **Separación entre bloques:** `space-y-6` o `gap-6`.
